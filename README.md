# GREEN-API Telegram Client

## Стек

React 19, TypeScript, Vite, React Router, Redux Toolkit (RTK Query), React Hook Form, Zod, CSS Modules, Node.js и Express.

## Локальный запуск

### Требования

- **Node.js**
- **npm** (поставляется вместе с Node.js)

### 1. Установка зависимостей

Откройте терминал в корневой папке проекта и выполните:

```
npm install
```

**Важно:** эту команду необходимо выполнить перед первым запуском приложения. Она установит все необходимые зависимости из `package.json`.

### 2. Запуск приложения

После успешной установки зависимостей выполните:

```
npm run dev
```

### 3. Открытие приложения

После запуска откройте в браузере:

[http://127.0.0.1:5173/](http://127.0.0.1:5173/)

Прокси GREEN-API запускается вместе с приложением. Дополнительные переменные окружения не требуются.

## Подключение GREEN-API

На странице подключения введите `apiUrl`, `idInstance` и `apiTokenInstance` авторизованного Telegram-инстанса GREEN-API.
